Informasi Sistem

Sistem Informasi Data Mahasiswa membantu pengelola program studi mencatat, melihat, dan menambah data mahasiswa secara terstruktur.

Fitur Utama

Aplikasi ini menyediakan tabel daftar mahasiswa aktif dan formulir input dengan validasi HTML5 agar data yang dimasukkan sesuai format.
